Where an agent's data access enters the framework

A subset of the connected cube, drilled into the foundational capability layer. Core capabilities are claims you cannot make about an event you never collected.

The connected cube — the established device

Maps the Data & Information Observability framework across operating model elements, capabilities and data types. Its capability face carries the five core capabilities only.

This figure drills one level below that face, into the foundational capabilities the cube does not render — which is where this workstream operates.

All five rest on the whole chain

Each core capability is an assertion about data access. None can be made where the access was never recorded — so each one depends on every capability below, not on a part of the layer.

The chain breaks here

No agreed convention carries actor identity or dataset identity for an agent's tool call, so the event cannot be connected and there is nothing to collect.

Alert, Store and Analyse are left with nothing to act on.
